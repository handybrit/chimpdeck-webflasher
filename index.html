Sunton ESP32-8048S050 SSH Terminal

Flash the terminal firmware to your Sunton 5 inch display, straight from this page. No command line, no esptool install.

How to use it

  1. Use desktop Chrome or Edge on a Mac or PC. Web Serial does not work in Safari, Firefox, or on an iPad.
  2. Plug the Sunton display into the computer with a USB data cable.
  3. Click Install above, then pick the Sunton serial port in the browser dialog. It is usually listed as USB-SERIAL CH340 or similar.
  4. When asked, choose to erase the flash for a clean first install. That wipes any old settings on the board.
  5. Wait for the flash to finish, then the display reboots into the launcher.

After flashing

On the display: open WiFi and connect, add a server in Server Profiles, pair a Bluetooth keyboard in Bluetooth Keyboards, then open SSH Terminal. Full instructions are in the repo README.

Firmware: merged image esp32-sunton-ssh-merged.bin, flashed to offset 0x0, ESP32-S3, 16 MB flash. Version 1.0.0.

Note: this firmware pairs with BLE keyboards only. The ESP32-S3 has no Classic Bluetooth, so a Classic-only keyboard will not appear in scans.
